## 三、走查中发现并修复的缺陷（2025-09-05 补记）

### 缺陷：检索元数据（含摘要）不传给 planner / writer
**现象**：主代理检索后把**精简文献清单（作者+题名+出处，无摘要）**传给 planner；writer 只拿到编号与用途描述，全程未读摘要。

**实证损伤**：planner 凭题名推断文献用途 → 县域协同治理文献（陈倩/吴玉韶）被误配为"覆盖面实证"论据 → auditor 第 3 轮抓出"内容匹配偏松"。

**根因**：协议写了"检索须返回完整摘要"，但**未规定传递机制**——检索工具在主代理手上，子代理拿不到检索原文。

**修复**（已同步 .dsh/prompt.md 与 publish 仓库）：
1. 新增**文献池文件** `_文献池_最新.md`：检索后完整条目（含摘要）必须落盘于此；
2. 新增**硬性传递协议**：委派 planner/writer/auditor 时须让其读取文献池或内联完整条目，**严禁只传精简清单**；
3. writer 规则加"**无摘要不引文**"；auditor 文献审计须以摘要核对观点归属；
4. planner 收到无摘要清单时有权拒绝并索要完整条目。

- citation-check.ps1 升级支持 `[n-m]` 范围引注（GB/T 7714 合法简写），此前误报孤儿。
