# demo/ — 演示工作区（项目根目录应长什么样）

> 本目录模拟一个**已经按本流水线运行了一段时间**的论文项目根目录，展示各台账工件
> 实际填好后的形态。复制本仓库做新项目时，把 demo/ 里的工件（STATUS.md、glossary.md、
> session-handoff.md）拷贝到你的项目根目录，清空内容按你的课题重填即可。
>
> 演示课题（虚构）：《城市社区居家养老服务供需匹配机制研究》——与 README 示例一致。

## 本目录包含

| 文件 | 对应模板 | 说明 |
|---|---|---|
| `STATUS.md` | `templates/STATUS.md` | 进度台账已填示例：可见"哪些章节已写/已审/待写" |
| `glossary.md` | `templates/glossary.md` | 术语口径基准已填示例：可见译名与概念定义如何登记 |
| `session-handoff.md` | `templates/session-handoff.md` | 交接卡已填示例：可见会话结束前如何留档 |
| `第三章第二节_正文.md` | — | 一节"已交付正文"样例（含 [n] 引注与文末参考文献） |
| `大纲.md` | — | 论文大纲（节选），演示目录文件如何组织 |

## 从 demo 到你的项目（三步）

1. 把 `STATUS.md` / `glossary.md` / `session-handoff.md` 拷到你的项目根目录；
2. 按你的开题报告重填（或让 Agent 用 `docs/customize-from-proposal.md` 的作业单代填）；
3. 开始写作后，每次任务前后让 steward 更新 STATUS.md，每会话结束填 handoff。

> 跨会话如何恢复、各工件何时更新，见 `docs/session-recovery.md`。
