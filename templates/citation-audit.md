# 引用三对照核验清单（人工 + 脚本）

> 交付任何正文前，须完成以下三对照。**引注体系由 `MODE.md` 的 `citation_style` 决定**，
> 三对照的具体形态随之不同（见第一节）。机械部分由 `scripts/citation-check.ps1` 自动执行；
> 第三对照需 librarian 人工在文献库（如 Zotero）完成。

## 一、先确认本文的引注体系

| `citation_style` | 典型场景 | 正文形态 | 文末排列 | 脚本参数 |
|---|---|---|---|---|
| `numeric` | 中文学位论文、部分中文期刊 | `[n]` 上标 | 按编号顺序，`citation_standard` 著录 | `-Style numbered` |
| `author-date` | 课程论文、部分社科期刊 | `（作者, 年份）` | 按作者姓氏字母序，**不编号** | `-Style author-date` |
| `footnote` | 部分人文类期刊与专著 | 页下脚注 | 文末另附参考文献 | **脚本不支持，人工核验** |

> 学位论文模式默认 `numeric` + GB/T 7714—2015；期刊论文模式**以目标期刊《投稿须知》为准**；
> 课程论文模式默认 `author-date`。**不要默认 GB/T 7714。**

## 二、三对照是什么

| 对照 | 内容 | 执行方式 |
|---|---|---|
| ① 正文引注 | `numeric`：正文 `[n]`（紧跟作者名或直接引文右引号之后）／`author-date`：`（作者, 年份）` | 脚本自动提取 |
| ② 文末参考文献 | 文末"参考文献"列表，按 `citation_standard` 著录 | 脚本自动提取 |
| ③ 文献库条目 | 文献库中真实存在的条目（含元数据与 PDF） | librarian 人工核对 |

## 三、脚本用法

```powershell
# 顺序编码制（学位论文、部分期刊）
powershell -ExecutionPolicy Bypass -File scripts/citation-check.ps1 -TextPath "第三章正文.md" -Style numbered

# 著者-年制（课程论文、部分社科期刊）
powershell -ExecutionPolicy Bypass -File scripts/citation-check.ps1 -TextPath "课程论文.md" -Style author-date
```

脚本会报告：

- **`numeric`**：正文引用但文末缺失 / 文末孤儿条目 / 编号跳号 / 多次引用沿用；
- **`author-date`**：正文引注在文末无法对应（含年份不符）/ 文末孤儿条目 / 年份清单；
- 输出零问题时，会打印待人工填写的第三对照单。

> ⚠️ **`author-date` 的机械核对为启发式判定**（按作者姓氏片段 + 年份匹配），存在少量误报
> （如同一作者多篇同年文献）。**最终以人工第三对照为准**。
>
> ⚠️ **`footnote` 体例无脚本支持**，须人工逐条核验页下注与文末条目的对应关系。

## 四、人工第三对照（librarian 逐条执行）

### 若为 `numeric`（顺序编码制）

对正文每个首次出现的 `[n]`：

- [ ] `[1]` → 文献库条目：<作者+年份+题名>；元数据齐全（卷期页码/DOI）；PDF 已挂载或注明待补
- [ ] `[2]` → ……（逐条列出）
- [ ] 每条都能在文献库「父集合」下找到对应条目，且归入正确主题子集合

### 若为 `author-date`（著者-年制）

对正文每个引注 `（作者, 年份）`：

- [ ] （作者1, 2020） → 文献库条目：<题名>；元数据齐全；PDF 已挂载或注明待补
- [ ] （作者2, 2021） → ……（逐条列出）
- [ ] 同一作者同年的多篇文献已用 a/b/c 区分（如 2020a、2020b），且正文与文末一致
- [ ] 每条都能在文献库中找到唯一对应条目

### 若为 `footnote`（脚注体例）

- [ ] 每个脚注的出处信息与文末参考文献条目一致（著录要素不得互相矛盾）
- [ ] 脚注序号连续，无重复、无跳号
- [ ] 转引（indirect citation）已如实标注"转引自"，未伪装为直接引用

## 五、通过标准

- ① 与 ② 的引注集合完全一致、顺序（或字母序）符合所选体例（脚本判定 ✅）；
- 每条 ① 都能在 ③ 找到唯一对应条目（人工判定 ✅）；
- 参考文献著录格式符合 `MODE.md` 的 `citation_standard`，卷期页码无杜撰
  （拿不到的已注明"待核验"）；
- **期刊论文模式另需**：字数仍在 `word_limit_hard` 以内，体例符合目标期刊《投稿须知》；
- 上述全部通过，正文方可交付。
