# 引用三对照核验清单（人工 + 脚本）

> 论文写作采用"顺序编码制"（GB/T 7714—2015）。交付任何章节前，须完成以下三对照。
> 机械部分由 `scripts/citation-check.ps1` 自动执行；第三对照需 librarian 人工在 Zotero 完成。

## 三对照是什么

| 对照 | 内容 | 执行方式 |
|---|---|---|
| ① 正文引注 | 正文中的 `[n]` 编号，紧跟作者名或直接引文右引号之后 | 脚本自动提取 |
| ② 文末参考文献 | 文末"参考文献"列表，按 GB/T 7714 著录 | 脚本自动提取 |
| ③ 文献库条目 | Zotero 中真实存在的条目（含元数据与 PDF） | librarian 人工核对 |

## 脚本用法

```powershell
powershell -ExecutionPolicy Bypass -File scripts/citation-check.ps1 -TextPath "<章节正文.md>"
```

脚本会报告：正文引用但文末缺失 / 文末孤儿条目 / 编号跳号 / 多次引用沿用。输出零问题时，会打印
待人工填写的 Zotero 对照单。

## 人工第三对照（librarian 逐条执行）

对正文每个首次出现的 `[n]`：

- [ ] `[1]` → Zotero 条目：<作者+年份+题名>；元数据齐全（卷期页码/DOI）；PDF 已挂载或注明待补
- [ ] `[2]` → ……（逐条列出）
- [ ] 每条都能在 Zotero「研究文献库」父集合下找到对应条目，且归入正确主题子集合

## 通过标准

- ① 与 ② 编号集合完全一致、顺序连续、无孤儿无缺失（脚本判定 ✅）；
- 每条 ① 的 `[n]` 都能在 ③ 找到唯一对应条目（人工判定 ✅）；
- 参考文献著录格式符合 GB/T 7714—2015，卷期页码无杜撰（拿不到的已注明"待核验"）；
- 上述三项全部通过，章节方可交付。
