# 摘要与关键词（模板 + 体例约定）

> **用途**：摘要不是"正文的缩写"，而是一份**独立文档**——它会被单独检索、单独阅读、
> 单独送审。学位论文摘要与期刊摘要的要求不同，故本模板按模式分节，取用对应那节。
>
> 机械核验由 `scripts/check-figures.ps1` 的 (A) 部分完成：
> 字数上限、结构化要素是否齐全、**自足性**、摘要中的样本量提取。
>
> 复制本模板到项目根目录使用（文件名建议 `摘要.md`，或直接作为正文首节）。

---

## 通用硬规则（三种模式都适用）

1. **自足**：摘要单独拿出来也必须读得懂。**不得出现指向正文的表述**——
   ❌ "如前所述" / "详见第二章" / "见表 3" / "下文将讨论"。
   摘要里若需引用图表，应把关键数据直接写进摘要，而不是让读者去翻图表。
2. **不引注**：多数体例要求摘要中不出现引注编号（`[1]`）或 `（作者, 年份）`。
   若目标刊/学校另有要求，以对方规定为准。
3. **数值须与正文一致**：摘要中的样本量（N）、关键系数、百分比，必须与
   `_分析结果_最新.md` 及正文逐处一致。**样本量不一致是高频硬伤**
   （如摘要 N=3826、表 2 N=3712 却未说明 114 例因何缺失）。
4. **不写"本文具有重要意义"** 这类空话——摘要要写**做了什么、发现了什么**。

---

## 一、学位论文模式

**篇幅**：中文摘要常见 300–800 字（按学校规范）；通常另需英文摘要（Abstract）对应。

**结构**（五要素，叙述式，不分小标题）：

```markdown
# 摘要

<研究背景与问题：1-2 句，点明研究的问题与必要性>
<研究方法：研究对象、数据/材料来源、样本量、分析方法>
<主要发现：核心结果，含关键数值>
<结论与贡献：本文的结论及其意义/创新点>
<关键词：3-5 个>
```

**关键词**：3–5 个，按学科通用词表选取，避免用无检索价值的泛词（如"研究""分析""问题"）。

**英文摘要**：与中文摘要内容对应，**术语须与 glossary.md 的统一英文名一致**；
由 consistency 复核中英口径是否一致（同一概念不得中英两套说法）。

## 二、期刊论文模式

**篇幅**：以目标刊《投稿须知》为准（常见 200–300 字中文 / 150–250 words 英文）。
**结构化还是非结构化**：按目标刊要求。多数医学与部分社科刊要求结构化摘要。

**结构化摘要**（若该刊要求）：

```markdown
# 摘要

**目的** <一句话说明研究目的>
**方法** <设计、对象、数据来源、样本量、主要测量与分析>
**结果** <主要发现，含关键统计量与置信区间>
**结论** <结论及其适用边界>

**关键词** <3-6 个>
```

**非结构化摘要**：按"背景—方法—结果—结论"顺序连续成段。

> ⚠️ **审稿人常据摘要决定是否细读全文**。摘要必须**在开头就点明研究缺口与本文贡献**
> （呼应 `modes/journal-article.md`"新在哪"的第一问）。
> 占比建议：背景 ≤25%，方法 ≈25%，**结果 ≈35%**，结论 ≤15%。

## 三、课程论文模式

**篇幅**：按教师要求；无明确要求时 150–300 字。
**结构**：常为一段式——问题 → 所用课程理论 → 分析要点 → 结论。
**是否需关键词**：视课程要求，通常不必。

> 课程论文摘要同样**自足**，但不必像期刊摘要那样强调"研究缺口"——
> 教师最关心的是**你是否用了课程理论**，摘要里应体现这一点。

## 交付前自检（逐项打勾）

- [ ] **字数**在要求范围内（跑 `check-figures.ps1 -MaxAbstract <上限>`）
- [ ] **自足**：无"如前所述/详见第N章/见表N"（脚本会检出）
- [ ] **无引注编号**（除非体例要求）
- [ ] 样本量与正文、表注、`_分析结果_最新.md` **四处一致**
- [ ] 关键数值与 `_分析结果_最新.md` 一致（**不得凭记忆填写**）
- [ ] 术语与 `glossary.md` 的统一译名一致；英文摘要术语与中文对应
- [ ] 关键词数量与选取符合要求，无泛词
- [ ] （期刊模式）已在开头点明缺口与贡献
- [ ] （学位论文模式）中英文摘要内容对应，无中英口径分歧
