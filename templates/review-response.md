# 审稿意见应答表（期刊论文模式专用）

> **用途**：期刊论文进入返修阶段后，对审稿人意见**逐条应答**。笼统回复"已按意见修改"
> 会被编辑视为敷衍，是返修被拒的常见原因。复制本模板到项目根目录使用。
>
> 仅在 `MODE.md` 的 `mode: journal-article` 且已收到外审意见时使用。
> 学位论文的答辩意见可借用本表结构，课程论文不需要。

## 修改稿自检

- [ ] 每条意见都有对应应答，**无遗漏、无"已修改"式空话**；
- [ ] 所有"接受"的意见都能在正文中找到具体落点（给出节号/表号/图号）；
- [ ] "说明理由"的条目给出了学术理由，语气礼貌、不对抗；
- [ ] 修改后字数**仍在 `MODE.md` 的 `word_limit_hard` 以内**（返修最容易超限）；
- [ ] 新增文献已走 librarian 落库流程；
- [ ] 正文引注与文末参考文献重新通过 `citation-check.ps1` 核验；
- [ ] 若审稿意见要求补充数据/实验，已在正文说明并（如需要）提供补充材料。

## 给编辑的回复信要点

- 开头：感谢编辑与审稿人，说明已按意见修改；
- 主体：**概述**主要修改（不重复应答表全文），突出实质性改动；
- 若有"说明理由"的条目，在此处礼貌澄清，避免编辑误读为回避；
- 结尾：说明修改稿如何提升了文章质量，并表示愿意进一步修改。
