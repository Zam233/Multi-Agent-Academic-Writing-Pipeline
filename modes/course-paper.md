# 模式 3：课程论文模式（course-paper）

> 适用：交给任课教师、算课程成绩的论文。与学位论文/期刊论文的核心差别是——**判据是
> "有没有达到这门课的要求"，而不是"有没有创新"**。课程论文通常不要求原创贡献，
> 但要求**正确运用课程所授理论/方法**，并且符合教师的具体要求。
>
> 使用前必须先读 [`_mode-overview.md`](_mode-overview.md) 建立 MODE.md。

## 一、课程论文模式的定位（先纠正一个常见误区）

**课程论文不是"缩小版的学位论文"。** 二者的判据不同：

| | 学位论文 / 期刊论文 | 课程论文 |
|---|---|---|
| 判据 | 有没有新贡献 / 能不能发表 | **有没有达成课程学习目标** |
| 创新性 | 必须有（按档位递进） | **不要求**；正确运用即可 |
| 理论运用 | 可发展、可修正理论 | **须忠实运用课程所授理论**（擅自改造反而失分） |
| 读者 | 盲审专家 / 审稿人 | 任课教师（他知道自己教了什么） |
| 篇幅 | 大（万字级） | 小（2 千 – 8 千字，严格按课程要求） |
| 结构 | 完整学术骨架 | 题 → 论述段，通常无目录、无独立文献综述章 |

> ⚠️ 因此 **auditor 在课程模式下不得用"创新性不足"作为退回理由**。要退回，
> 须指出"未达成课程要求"或"理论运用有误"或"论证/文献有硬伤"。

## 二、开工前必须确认的三件事

课程论文的成败高度取决于**是否对齐教师要求**，而这些要求往往只写在课程大纲或口头讲过。

| # | 确认项 | 为什么 | 缺失时怎么办 |
|---|---|---|---|
| 1 | **课程名 + 课程大纲/要求原文** | 决定选题范围与理论落点 | 请用户提供；确实没有则按"该课程通用要求"给假设并标 ⚠️待确认 |
| 2 | **教师具体要求**（篇幅、引注体例、提交格式、截止时间、是否允许自选题目） | 硬性合规项，最易失分 | 同上 |
| 3 | **评分点 / 评分细则（rubric）** | 有 rubric 就逐条对齐——这是**提分最直接的手段** | 无 rubric 则按"内容/理论运用/论证/文献/格式"五维自建临时评分点并告知用户 |

**若教师给了评分细则，它是课程模式下的第一优先级文档**——审计与预审都以它为准，
而不是以通用学术标准为准。

## 三、结构骨架

课程论文结构按课程类型分化，**不预设学科**：

### 通用骨架（多数课程适用）

```
题目
一、问题提出 / 引言          ← 交代选题理由与本文要解决的问题
二、理论/概念框架            ← 运用课程所授理论（课程论文的重心所在）
三、分析 / 论证              ← 主体，可分 2-3 个层次
四、结论与反思               ← 简短
参考文献
```

### 常见变体

| 课程类型 | 变体结构 |
|---|---|
| 理论研讨课 | 概念界定 → 理论脉络 → 争论焦点 → 我的判断 |
| 方法/实验课 | 问题 → 方法设计 → 结果 → 讨论 |
| 案例分析课 | 案例描述 → 分析框架 → 分析 → 启示 |
| 读书报告型 | 著作核心论点 → 论证结构评析 → 与课程理论的关联 → 评价 |
| 文献综述型 | 主题界定 → 文献梳理 → 综合评述 → 研究展望 |

### 篇幅纪律

课程论文**最忌讳超长**——教师给的是区间，超出通常不加分（有些课程直接扣分）。
planner 的篇幅分配按区间**取中下位**规划，留出修订余量：

| 要求区间 | 规划目标 |
|---|---|
| 2 – 3 千字 | 3 千字以内，论述 2 个层次即可 |
| 3 – 5 千字 | 4 千字左右，论述 3 个层次 |
| 5 – 8 千字 | 6 千字左右，可有独立理论框架节 |

## 四、与课程理论的咬合（课程论文的核心得分点）

这是课程论文区别于"随便写点什么"的关键。writer 必须做到：

1. **明确点名课程中的理论/概念/模型**，并用其组织分析（不是把理论当装饰性引言）；
2. **忠实于课程口径**——按课上讲的定义与框架来用，不擅自"发展"或"修正"理论；
3. **分析过程体现理论的操作**——例如用课程的分析维度逐项展开，而非只在开头提一句；
4. **适当回扣**——结论处回到课程理论，说明本文的分析印证/补充了什么。

consistency 在课程模式下额外核对：**本文使用的理论口径是否与课程所授一致**
（这是课程论文特有的审查项，学位论文/期刊论文没有）。

## 五、评审口径：教师的评分点

auditor 第 5 维在课程模式下改为「**课程评分点**」。有 rubric 时逐条对齐；无 rubric 时按五维自建：

| 维度 | 教师实际在看什么 | 常见失分 |
|---|---|---|
| 内容与选题 | 是否切题、是否在规定范围内 | 跑题、选题过大 |
| 理论运用 | 是否用了课程理论、用得对不对 | 理论当装饰、用错概念 |
| 论证 | 有没有自己的分析、逻辑是否连贯 | 观点堆砌、无论证 |
| 文献 | 是否引了必要文献、格式是否规范 | 不引文献、文献造假 |
| 格式与规范 | 篇幅、引注、排版是否合规 | 超/欠篇幅、引注体例混乱 |

**blind-review 在课程模式下改为模拟任课教师**，按上述评分点设问，通常**只需对本篇跑一次**
（课程论文篇幅小，不需要学位论文那种滚动预审）。

## 六、默认引注体系

- 课程要求为准；无明确要求时，**默认著者-年制**（`（作者，年份）`，APA 或 Chicago author-date 风格）；
- 文末参考文献按所选体例著录（APA 7th / Chicago 17th 等），**不默认 GB/T 7714**
  （GB/T 7714 是本仓库中文学位论文与部分中文期刊的默认，课程论文未必适用）；
- `citation-check.ps1` 用 `-Style author-date` 核验；
- **文献量可以少，但真实性标准不降**——课程论文同样不得臆造文献，
  教师一旦发现编造引用，后果通常比"少引两篇"严重得多。

## 七、交付物清单（课程论文）

| 交付物 | 说明 | 谁维护 |
|---|---|---|
| 课程论文正文 `.md` | 全篇（含题目、论述、参考文献） | writer → 主代理 |
| `STATUS.md` | **题目/段落清单 + 进度**（粒度最简） | steward |
| `glossary.md` | 术语与概念口径基准（含课程理论口径） | consistency 登记 |
| `session-handoff.md` | 会话交接卡 | steward |
| 课程要求对照自查表 | 逐条核对教师要求与评分点 | 主代理 |
| `MODE.md` | 本模式配置（mode: course-paper） | 部署时生成 |

> **不需要**：目录同步、章节编号防错、字数占比预算表、滚动式评审预审机制、投稿信与审稿应答表。
> 课程论文的流程应保持**轻量**——过度流程化反而拖慢交付。
