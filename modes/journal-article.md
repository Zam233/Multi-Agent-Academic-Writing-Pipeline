# 模式 2：期刊论文模式（journal-article）

> 适用：要投给期刊、会走审稿流程的稿件。与学位论文最大的不同在于——**读者是匿名审稿人，
> 判据是"能不能发"，而且有硬性字数上限**。学位论文可以"求全"，期刊论文必须"求尖"。
>
> 使用前必须先读 [`_mode-overview.md`](_mode-overview.md) 建立 MODE.md。

## 一、开工前必须确认的五件事（缺一不可）

期刊论文模式**比其他两个模式更依赖前置信息**——目标期刊没定，体例、字数、结构全都无从谈起。
planner 拿到任务后，若 `MODE.md` 缺下列任一项，**必须先向用户补齐，不得开工**：

| # | 确认项 | 为什么必须有 | 缺省后果 |
|---|---|---|---|
| 1 | **目标期刊** | 引注体例、结构习惯、行文风格都随刊不同 | auditor 无法做"期刊适配"审计 |
| 2 | **期刊层级**（CSSCI / SSCI Q1 / 核心 / 普刊） | 决定创新性门槛与文献要求 | 标准失准，改稿方向错 |
| 3 | **稿件类型**（原创研究 / 综述 / 案例 / 方法 / 书评） | 决定结构骨架与篇幅 | 写出的结构可能根本不是该刊收的类型 |
| 4 | **字数上限（硬）** | 超限常见结果是被**直接退稿**（编辑初审就拦） | 写完再砍，伤筋动骨 |
| 5 | **引注体例**（序号制 or 著者-年制 or 脚注） | 决定正文引注形态与文末著录格式 | 交付后须整体返工 |

> 补充确认项（有条件时问）：该刊近期是否发过同类选题？有没有需规避的"已发过"角度？
> 是否要求中英文摘要、基金项目标注、作者贡献声明？

## 二、四种稿件类型的结构骨架

**不预设学科**——以下骨架适用于多数实证类学科，但理工科（实验/建模/算法）与
人文（思辨/考据）的具体章节名差异较大，**以目标期刊近期同类文章的实际结构为准**。
planner 应在第一步检索并通读目标期刊近 2-3 年的 2-3 篇同类文章，提取其结构骨架再规划。

### 类型 1：原创研究（实证类，最常见）

```
题目（信息量优先，避免"……的研究"式空题）
摘要（结构化或非结构化，按刊要求）＋ 关键词
1 引言            ← 研究缺口 → 本文贡献（一段内说清），不做长篇综述
2 文献综述 / 理论基础  ← 只综述"与缺口相关的"，不必全
3 研究设计 / 方法      ← 数据、变量、模型、识别策略、稳健性设计
4 结果与分析
5 讨论                ← 与文献对话：我的结果支持/挑战了谁
6 结论与局限
参考文献
```

### 类型 2：综述

```
1 引言（为什么要现在综述）
2 检索策略与纳入标准 ← 综述的"方法"，必须有，否则被质疑主观
3 主题分述（3-5 个主题，每主题一小节）
4 研究缺口与未来议程 ← 综述的价值所在：指出大家都没做什么
5 结论
```

### 类型 3：案例研究

```
1 引言
2 理论框架 / 分析视角
3 案例选择与材料来源 ← 说明"为什么是这个案例"（典型性/极端性/可及性）
4 案例分析（通常按时间线或按分析维度展开）
5 讨论（案例如何回应理论）
6 结论
```

### 类型 4：方法 / 工具

```
1 引言（已有方法为何不够）
2 相关工作
3 本文方法（核心，篇幅主体）
4 实验设计与对比（基准、指标、对照组）
5 结果与讨论
6 结论与未来工作
```

### 类型 5：书评 / 短评

篇幅短（1-3 千字），结构随刊，通常无摘要与关键词。**若用户要写这类，流水线可简化**：
规划与审计仍要走，但 blind-review 通常不必跑。

## 三、字数上限是硬约束（期刊模式的核心纪律）

学位论文模式里字数是"预算"（可超可欠，报偏差即可）；期刊模式里字数是**闸门**（超了就被拦）。

### 规则

1. **`MODE.md` 的 `word_limit_hard` 是硬上限**，并须注明口径（是否含摘要、图表、参考文献）；
2. **planner 必须先做减法再分配**：整篇规划时就要把上限拆到每一节，留 5% 余量（改稿通常还会涨）；
3. **writer 每节产出后立即报字数**，累计接近上限时**主动压缩而非继续扩写**；
4. **auditor 第 5 维必须含"字数合规"检查**——超限即为"需修订"，不是提示级问题；
5. steward 在版本台账里实时记录字数 vs 上限。

### 常见的期刊论文压缩手法（供 writer 参考）

- 文献综述从"按时间罗列"改为"按争论焦点归类"，只留与缺口直接相关的；
- 方法部分把标准操作细节移入附录或补充材料；
- 结果与讨论合并（该刊允许时）；
- 删除"研究意义"式铺陈——审稿人不看，引言第一段就进缺口。

## 四、审稿人视角：匿名外审真正在问什么

auditor 与 blind-review 在期刊模式下按下列顺序设问（这是审稿意见单的实际结构）：

| # | 审稿人问题 | 对应审计动作 |
|---|---|---|
| 1 | **新在哪？** 与已有文献的差别是什么？ | 检查引言是否在**第一页内**点明缺口与贡献；贡献是否可一句话概括 |
| 2 | **证据够不够？** 结论是否被数据/材料支撑？ | 检查论证链有无跳步；因果表述是否超出识别策略能支持的范围 |
| 3 | **做得对不对？** 方法是否适配、是否规范？ | 检查方法-问题匹配；效度/信度/稳健性是否交代 |
| 4 | **读起来顺不顺？** 结构、语言、图表 | 检查逻辑结构与语言机器感（AI 味） |
| 5 | **合不合本刊？** 选题、体例、篇幅 | **期刊适配审计**：体例是否合规、字数是否超限、题材是否符合该刊范围 |
| 6 | **有没有硬伤？** 伦理、数据可得性、利益冲突 | 检查是否需伦理声明、数据可用性声明 |

**"期刊适配"是期刊模式独有的第 5 维内容**——学位论文只需合规学校格式，
期刊论文还需合规**这一家期刊**的具体要求。

## 五、投稿与返修：以"版本"为单位推进

期刊模式的 `structure_unit` 是 `全篇`——**没有"下一节"可写**，改稿以版本为单位：

```
初稿 v1 ──自查/预审──▶ 投稿 v2 ──外审意见──▶ 返修稿 v3 ──▶ 终稿 v4
```

### 版本台账（steward 维护，替代学位论文的四态章节清单）

| 版本 | 状态 | 字数 | 说明 |
|---|---|---|---|
| v1 初稿 | 已过审计 | 10500 | 已压至上限内 |
| v2 投稿版 | 已投出 | 10300 | 按《投稿须知》调整体例 |
| v3 返修稿 | 进行中 | 10800 | 回应 3 位审稿人共 11 条意见 |
| v4 终稿 | 待定 | - | - |

### 审稿意见应答表（返修阶段的核心工件）

返修时**必须逐条应答**，不得笼统回复"已按意见修改"。每条一行：

| # | 审稿人意见（原文摘录） | 处理方式（接受/部分接受/说明理由） | 修改位置 | 修改说明 |
|---|---|---|---|---|
| 1 | <意见1> | 接受 | 第 3.2 节 | 补充稳健性检验，见表 4 |
| 2 | <意见2> | 部分接受 | 第 4 节 | 因数据限制无法完全按建议，已在局限中说明 |
| 3 | <意见3> | 说明理由 | — | 该建议基于对本文方法的误解，已澄清（见回复信） |

> 应答表是 `templates/review-response.md` 模板。**"部分接受"与"说明理由"是正当的**——
> 不必对每条意见全盘接受，但必须给出学术理由，不得沉默回避。

## 六、默认引注体系（与学位论文的关键差异）

- **以目标期刊《投稿须知》为准**，不是以 GB/T 7714 为准；
- 中文社科期刊常见**著者-年制**（正文 `（作者，年份）`），与学位论文的 `[n]` 完全不同；
- 理工科与部分中文核心期刊沿用**顺序编码制** `[n]`；
- 人文类期刊可能使用**脚注**体例（页下注 + 文末参考文献）；
- `citation-check.ps1` 用 `-Style numbered` 或 `-Style author-date` 对应核验；
  脚注体例暂无脚本支持，须人工核验（脚本会提示）。

## 七、交付物清单（期刊论文）

| 交付物 | 说明 | 谁维护 |
|---|---|---|
| 稿件正文 `.md` | 全篇（含摘要、关键词、正文、参考文献） | writer → 主代理 |
| `投稿信 / cover letter` | 致编辑，说明选题价值与适配性（按需） | 主代理 |
| `审稿意见应答表` | 返修阶段，逐条应答 | 主代理 + writer |
| `STATUS.md` | **版本台账** + 字数 vs 上限 | steward |
| `glossary.md` | 术语与概念口径基准 | consistency 登记 |
| `session-handoff.md` | 会话交接卡 | steward |
| `MODE.md` | 本模式配置（mode: journal-article） | 部署时生成 |

> **不需要**：目录同步、章节编号防错、字数预算占比表（那些是学位论文模式的工件）。
