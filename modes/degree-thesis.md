# 模式 1：学位论文模式（degree-thesis）

> 适用：交给学校/学院评审、有学位授予含义的论文。含**本科（bachelor）／硕士（master）／
> 博士（doctor）**三档。三档共用同一条流水线，差别在**篇幅预算、创新性门槛、结构规约与评审口径**。
>
> 使用前必须先读 [`_mode-overview.md`](_mode-overview.md) 建立 MODE.md；本文件解释"为什么"，
> `MODE.md` 规定"这一篇具体怎么办"。

## 一、本 / 硕 / 博三档速查

| 维度 | 本科（bachelor） | 硕士（master） | 博士（doctor） |
|---|---|---|---|
| 常见篇幅 | 0.8 – 1.5 万字 | 3 – 5 万字 | 6 – 12 万字 |
| 结构单元 | 章 → 节 | 章 → 节（可到三级） | 章 → 节 → 目 |
| 章节数 | 4 – 5 章 | 5 – 6 章 | 6 – 8 章 |
| 核心要求 | 规范运用方法解决一个明确问题 | 独立完成研究，有**一定新意** | **理论/方法层面的原创贡献** |
| 创新性门槛 | 用对方法、把问题说清楚即可，不要求创新 | 至少一项：新问题、新数据、新方法、新解释 | 必须成体系地推进某一学术问题，可被同行引用 |
| 文献量级 | 15 – 30 篇 | 40 – 80 篇 | 100 – 200 篇+ |
| 外文文献 | 不作硬性要求 | 应有相当比例 | 必须充分覆盖国际前沿 |
| 研究方法要求 | 会用一种规范方法 | 方法适配问题并说明效度/信度 | 方法本身可有方法论反思与推进 |
| 评审口径 | 指导教师 + 评阅 + 答辩 | **盲审** + 答辩 | **双盲外审**（含同行评议）+ 预答辩 + 答辩 |
| 典型失败模式 | 综述堆砌、无问题意识、结论空泛 | 章节失衡、机制说不透、文献与论点脱节 | 创新点不成立、理论与材料两张皮、贡献不可辨识 |
| 审计重心 | 规范性（结构完整、格式合规、无抄袭） | 论证链完整 + 机制/因果说透 | **贡献可辨识性** + 学术对话深度 |

> **档位取不准时**：向用户确认。"本科毕业论文"与"硕士学位论文"的篇幅与创新要求差一个量级，
> 判错会导致 planner 的篇幅分配整体失准。**不得按最保守档位默认。**

## 二、创新性门槛的梯度（auditor 与 blind-review 共用此标尺）

这是三档之间**最实质**的差异。审计时按 level 取对应标尺，不得用博士标尺要求本科论文，
也不得用本科标尺放过博士论文。

### 本科：不要求创新，要求**规范**

- ✅ 通过：问题明确、结构完整、方法使用正确、文献真实、结论有据、格式合规；
- ❌ 退回：抄袭（含 AI 代写后不核验导致的失实）、数据/文献造假、结构残缺、方法与问题不匹配。

### 硕士：要求**一项**可辨识的边际贡献

至少满足下列之一，且必须能在摘要与结论中被**明确指出**：

1. 新问题：把既有研究未处理的现象/群体/情境纳入考察；
2. 新数据/新案例：一手材料、调查、实验、档案等，且说明获取方式与代表性；
3. 新方法：将其他领域方法迁移并论证其适配性；
4. 新解释：对既有现象给出与主流不同的机制解释，并给出证据。

- ❌ 退回：通篇综述而无自己的分析；贡献只是"把 A 和 B 放在一起谈"；结论无法回溯到证据。

### 博士：要求**成体系**的原创推进

1. 贡献须能被同行辨识、命名、引用（不是"我做了一个研究"，而是"我提出了 X 机制/修正了 Y 模型"）；
2. 须与既有学术脉络**正面交锋**——明确说明推进了谁、在什么意义上推进、边界在哪；
3. 理论与经验材料须**双向咬合**（不是"理论一章 + 案例一章"两张皮）；
4. 方法须有反思：为什么此法能回答此问题，其局限如何影响结论边界。

- ❌ 退回：创新点无法用一句话说清；贡献只在"应用了某理论到某地"层面；理论章与实证章互不引用。

## 三、结构规约（学位论文特有）

### 通用骨架

```
绪论（问题提出 / 研究意义 / 文献综述 / 研究设计 / 创新点）
理论框架与分析框架      ← 与 mode 无关，学科自定义
研究设计 / 方法
实证 / 分析章节（2-4 章，全文主体）
结论与讨论（含局限与展望）
参考文献 / 致谢 / 附录
```

**不预设学科理论**：理论框架的名称、数量与形态由 `MODE.md` 的 `discipline` 与用户的
开题报告决定——文科可能是"概念框架 + 分析维度"，理工科可能是"数学模型 + 实验设计"，
医学可能是"假设 + 队列/试验设计"。planner **不得套用模板化的理论章节写法**。

### 篇幅预算纪律

学位论文的头号质量问题是**章节失衡**。planner 在整篇规划阶段就必须产出字数预算表：

| 章节 | 预算字数 | 占比 |
|---|---|---|
| 绪论 | <N> | ~10% |
| 理论/框架章 | <N> | ~15% |
| 方法章 | <N> | ~10% |
| 实证/分析章（主体） | <N> | **~45-55%** |
| 结论与讨论 | <N> | ~10% |

规则：

- **主体分析章必须是全文最厚的一段**——占了不到 40% 说明前面铺垫过多（这是最常见的学位论文病）；
- 绪论超 15% 通常意味着文献综述失控，应压缩或拆入独立综述章；
- 每次写作任务完成后，由 steward 在 `STATUS.md` 累计实际字数与预算的偏差，**偏差超过 20% 必须报给用户**，不得默默继续。

### 目录同步（硬性）

学位论文有目录约束，**任何标题或结构改动（含小节改名）必须同步到大纲、STATUS.md 与
论文目录**，不得只改正文不改目录。这是 steward 的核心职责，也是 journal / course 模式不需要的。

## 四、评审口径与流水线适配

### 盲审 / 答辩真正在意什么

按档位排序（auditor 与 blind-review 以此设问）：

1. **问题值不值得研究**（本科也要问）——是伪问题吗？有人关心吗？
2. **文献综述是不是真的综述**（硕士及以上重点）——有没有对话，还是流水账？
3. **证据能不能支撑结论**（核心）——跳步了吗？反例处理了吗？
4. **贡献可辨识吗**（硕士及以上）——一句话说得清吗？
5. **规范性**（全部档位）——格式、引注、图表、附表。

### 模式适配要点

- **planner**：规划粒度是"某一节"，但必须同时交代本节与全篇论点线的咬合点、以及在字数预算中的配额；
- **writer**：产出达 `MODE.md` 所定档位的质量；篇幅遵守 planner 的配额，不得自行膨胀；
- **auditor**：第 5 维用「**盲审标准**」——语言与篇幅是否符合该档位的盲审质量要求；
- **blind-review**：模拟**不知作者意图的盲审专家**，按上文"盲审真正在意什么"逐条设问，
  并对**本节及此前全部已写章节**做滚动预审（这条在另两个模式里通常不需要）；
- **consistency**：除术语/概念/论点口径外，**必须核对章节编号与标题**是否与大纲、STATUS.md 同步；
- **steward**：维护"已写/待写/已审/已预审"四态章节清单 + 字数预算偏差 + 目录同步。

## 五、交付物清单（学位论文）

| 交付物 | 说明 | 谁维护 |
|---|---|---|
| `论文.docx` | 正文主文件（作者维护，Agent 只读转换） | 用户 |
| `_进度_最新.md` | docx 快照（docx2md.ps1 产物） | 脚本 |
| 各章节 `.md` | 已交付正文，建议一节一文件 | writer → 主代理 |
| `STATUS.md` | 四态章节清单 + 字数偏差 | steward |
| `glossary.md` | 术语与概念口径基准 | consistency 登记 |
| `session-handoff.md` | 会话交接卡 | steward |
| `大纲.md` / 目录 | 结构与编号基准 | 用户 + steward 同步 |
| `MODE.md` | 本模式配置（mode: degree-thesis） | 部署时生成 |
