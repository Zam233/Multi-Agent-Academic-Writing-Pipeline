# 用开题报告自动定制提示词（引导 Agent 的作业单）

> 目标：把 `prompts/system-prompt.md`（模板版）定制成**属于你的版本**——直接用于你的论文课题。
> 你不需要手工逐段改写：把下面的作业单连同你的开题报告一起交给 Agent（Codex 或 DeepSeek Harness 均可），
> 让它输出两个文件：定制后的 `prompts/system-prompt.md` 与根目录 `AGENTS.md`。

## 适用前提

- 你已有一份**开题报告**（docx / pdf / md 均可），其中包含：研究主题与题目、研究背景与问题意识、核心概念与理论工具、论文结构与章节大纲、参考文献方向。
- 你的 Agent 环境已能读写本仓库文件。

## 作业单（把下面这段原样发给 Agent，替换其中的 <> 为你的信息）

```text
请以本仓库为工作目录，执行「开题报告 → 定制提示词」任务。

## 输入材料
项目根目录下的开题报告文件：<开题报告文件名.docx>（若无法直接读取 docx，
请先用 PowerShell 解出 word/document.xml 转成 markdown 快照再继续）。

## 任务
1. 通读开题报告，提取：研究主题与题目、核心问题意识（含对既有研究的批判）、
   核心理论/框架及关键机制模型、章节结构大纲、拟用术语清单（含外文术语的选定译名）。
2. 打开 prompts/system-prompt.md（模板版），按开题报告内容执行以下替换：
   - 「研究课题的底层学术画像」整段：按模板括号里的同构句式，改写为开题报告的真实内容
     （外部路径批判 → 微观机制问题 → 行动者认同/行为问题；1-2 个理论框架 + 1 个机制模型）；
   - 「三大核心功能」示例中的章节标题、示例句：换成开题报告大纲里的真实章节；
   - 「术语与一致性审查」中提到的术语示例：换成开题报告的关键术语与译名；
   - 其余流程性内容（第〇步～第五步、角色分工、行为准则）保持不动。
3. 把定制结果写回两个位置：
   - prompts/system-prompt.md（覆盖为你的定制版）；
   - AGENTS.md（Codex 项目指令：内容与定制版 system-prompt.md 一致，
     作为项目根目录的指令入口——Codex 会自动读取）。
4. 完成后输出一份「定制报告」：列出你做了哪些替换、哪些占位符仍需人工确认
   （如文献库父集合键、模型路由等），以及建议作者人工复核的段落。

## 约束
- 不得改动模板的流水线结构（第〇步～第五步）与七个角色定义；
- 涉及用户隐私的信息（真实姓名、院校、导师）在 AGENTS.md 中一律用 <占位符>，
  不要在仓库中写入真实个人信息；
- 完成后不得自行 push，等待作者审阅。
```

## 使用 Codex 执行

```bash
codex "执行 AGENTS.md 定制任务：读取开题报告并生成 prompts/system-prompt.md 与 AGENTS.md，作业单见 docs/customize-from-proposal.md"
```

或将作业单全文粘贴进 `codex` 会话。

## 使用 DeepSeek Harness 执行

把作业单全文粘贴进 DSH 会话即可；DSH 主代理会按提示词协议自动完成读取、改写与写回（docx 转换步骤已内建于作业单第 1 步）。完成后把生成的 `prompts/system-prompt.md` 内容放入项目 `.dsh/prompt.md` 即完成装载（见 README Quickstart 方式 B）。

## 人工复核清单（Agent 输出后必做）

- [ ] 底层学术画像是否准确反映你的问题意识（不是套话）；
- [ ] 理论工具与机制模型是否与开题报告一致；
- [ ] 大纲章节编号是否与你的最新目录一致；
- [ ] 占位符是否已全部处理或标注"待确认"；
- [ ] AGENTS.md 中无真实姓名/院校/导师信息。
