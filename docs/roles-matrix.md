# 角色职责速查 + 模型路由示例

## 七个角色一览

| 角色 id（显示名） | 一句话职责 | 关键硬性规则 |
|---|---|---|
| planner（规划专家） | 检索文献、定论证结构与篇幅，产出规划报告 | 必须暂停等用户确认；不写作 |
| writer（成文专家） | 严格按已确认规划撰写正文 | 未确认不动笔；不经审计不交付 |
| auditor（审计专家） | 单节五维审计（学术规范/逻辑/文献/盲审/AI味） | 只报告不改写；通过才算完 |
| librarian（文献管理员） | 核验文献、补元数据、合规取 PDF、落库归类 | 用到一篇落一篇；禁盗版站 |
| consistency（术语与一致性审查） | 对照此前全部章节查术语/概念/论点/编号漂移 | 输出差异清单，冲突退回 writer |
| blind-review（盲审预审） | 模拟盲审对本节+此前全部章节滚动预审 | 按需触发，非每节必跑 |
| steward（大纲与进度管家） | 维护四态进度清单、同步大纲目录、防编号错乱 | 标题改动必须同步目录 |

## 委派方式

在支持角色路由的宿主环境中，形如：

```
subagent_role(role: "planner",  prompt: "...")
subagent_role(role: "writer",   prompt: "...")
subagent_role(role: "auditor",  prompt: "...")
subagent_role(role: "librarian", prompt: "...")
subagent_role(role: "consistency", prompt: "...")
subagent_role(role: "blind-review", prompt: "...")
subagent_role(role: "steward",  prompt: "...")
```

## 模型路由建议（泛化档位）

> 模型绑定是**宿主环境配置**，不写死在系统提示词里——主代理不得自行指定模型，统一由 settings/路由层绑定，便于一处切换、全局生效。档位按**能力取向**给出，具体型号由使用者按预算与可用模型自行填入。

| 角色 | 职责定位 | 建议档位（能力取向） |
|---|---|---|
| planner | 检索 + 结构化规划 | 中强推理档（长上下文 + 检索工具） |
| writer | 长文成文 | 长文写作强档（输出稳定、擅长学术文风） |
| auditor | 找茬审计 | 最强可用档（批判性与细节识别优先） |
| librarian | 元数据 + 落库 | 性价比档（结构化输出 + 工具调用） |
| consistency | 全文口径比对 | 长上下文强档（能容纳全文基准） |
| blind-review | 滚动盲审 | 最强可用档（与 auditor 同级或更强） |
| steward | 进度清单维护 | 轻量档（低成本高频调用） |

> 注意：模型绑定是**宿主环境配置**，不写死在系统提示词里——主代理不得自行指定模型，统一由 settings/路由层绑定，便于一处切换、全局生效。
