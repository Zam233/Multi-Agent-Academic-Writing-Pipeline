# 角色职责速查 + 模型路由示例

> **模式先行**：所有角色在执行任务前都必须先读项目根目录 `MODE.md`，以其中的参数覆盖本文件与
> 各自角色文件里的默认值。模式规格见 `modes/_mode-overview.md`。

## 七个角色一览

| 角色 id（显示名） | 一句话职责 | 关键硬性规则 |
|---|---|---|
| planner（规划专家） | 检索文献、定论证结构与篇幅，产出规划报告 | 必须暂停等用户确认；不写作 |
| writer（成文专家） | 严格按已确认规划撰写正文 | 未确认不动笔；不经审计不交付 |
| auditor（审计专家） | 单节五维审计（学术规范/逻辑/文献/**模式评审口径**/AI味） | 只报告不改写；通过才算完 |
| librarian（文献管理员） | 核验文献、补元数据、合规取 PDF、落库归类 | 用到一篇落一篇；禁盗版站 |
| consistency（术语与一致性审查） | 对照此前全部已写内容查术语/概念/论点/编号漂移 | 输出差异清单，冲突退回 writer |
| blind-review（评审预审） | 按模式模拟盲审专家/匿名审稿人/任课教师做预审 | 按需触发，非每节必跑 |
| steward（结构与进度管家） | 维护进度台账、同步结构、防编号错乱、跨会话恢复 | 学位论文下标题改动必须同步目录 |

## 角色 × 模式 行为对照

同一角色在三个模式下的**职责不变，靶子不同**。委派时必须在 prompt 中给出 `MODE.md` 路径。

| 角色 | degree-thesis | journal-article | course-paper |
|---|---|---|---|
| **planner** | 规划"某一节"，咬合全篇论点线；产出字数预算表 | 规划**整篇骨架**（缺口→贡献→证据链→结论）；从硬上限反推篇幅 | 规划题面→论述段落→课程理论落点；篇幅取区间中下位 |
| **writer** | 按节成文，达该档位盲审质量 | 按期刊体例成文，**严守字数上限**，摘要/关键词/图表齐备 | 按论述段成文，突出与课程理论的咬合 |
| **auditor** | 第 4 维＝**盲审标准**（含档位创新性门槛） | 第 4 维＝**审稿人口径**（含期刊适配与字数合规） | 第 4 维＝**课程评分点**（不得以创新性不足退回） |
| **librarian** | 全量落库，按主题归子集合，关注覆盖面与时效 | 全量落库 + 标注该文献对"研究缺口"的作用 | 落库从简，**真实性标准不降** |
| **consistency** | 术语/概念/论点 + **章节编号标题同步** | 术语/概念/论点 + **摘要-正文-结论三处口径一致** | 术语/概念/论点 + **理论口径与课程所授一致** |
| **blind-review** | 模拟**盲审专家**，本节+此前全部章节**滚动**预审 | 模拟**匿名审稿人**（新在哪/证据够不够/合不合本刊） | 模拟**任课教师**（按评分点），通常只跑一次 |
| **steward** | 四态章节清单 + 字数偏差 + 目录同步 + 防编号错乱 | **稿件版本台账** + 审稿意见应答表 + 字数实时核对 | 题目清单 + 进度 |

## 委派方式

在支持角色路由的宿主环境中，形如：

```
subagent_role(role: "planner",  prompt: "...（含 MODE.md 路径）...")
subagent_role(role: "writer",   prompt: "...（含 MODE.md 路径）...")
subagent_role(role: "auditor",  prompt: "...（含 MODE.md 路径）...")
subagent_role(role: "librarian", prompt: "...")
subagent_role(role: "consistency", prompt: "...")
subagent_role(role: "blind-review", prompt: "...（含 MODE.md 路径）...")
subagent_role(role: "steward",  prompt: "...")
```

**委派三件套**（每次委派 planner / writer / auditor / blind-review 时都要带）：

1. `MODE.md` 路径（模式与档位、字数标准、引注体系、评审口径）；
2. 结构单元在整体中的位置（前文衔接用）；
3. 拟引文献的**完整条目**（含摘要）或其落盘位置 `_文献池_最新.md`。

## 模型路由建议（按模式分档）

> 模型绑定是**宿主环境配置**，不写死在系统提示词里——主代理不得自行指定模型，统一由
> settings/路由层绑定，便于一处切换、全局生效。档位按**能力取向**给出，具体型号由使用者按
> 预算与可用模型自行填入。

| 角色 | 职责定位 | 建议档位（能力取向） |
|---|---|---|
| planner | 检索 + 结构化规划 | 中强推理档（长上下文 + 检索工具） |
| writer | 长文成文 | 长文写作强档（输出稳定、擅长学术文风） |
| auditor | 找茬审计 | 最强可用档（批判性与细节识别优先） |
| librarian | 元数据 + 落库 | 性价比档（结构化输出 + 工具调用） |
| consistency | 全文口径比对 | 长上下文强档（能容纳全文基准） |
| blind-review | 评审预审 | 最强可用档（与 auditor 同级或更强） |
| steward | 进度清单维护 | 轻量档（低成本高频调用） |

### 按模式调整资源投入

三个模式的文本量与风险不同，模型档位可相应调整：

| 模式 | 建议调整 |
|---|---|
| degree-thesis（博/硕） | 按上表满配——篇幅大、跨会话多、盲审风险高，auditor 与 blind-review 尤其不能省档 |
| degree-thesis（本科） | planner/writer 可降一档；auditor 仍建议保持强档（规范性硬伤最伤分） |
| journal-article | writer 用强档（期刊语言要求高）；**新增"期刊适配"检查**，auditor 须能读目标期刊体例；篇幅小，长上下文需求低于学位论文 |
| course-paper | 全流程可整体降档，auditor 保持中档即可；**不必为短文配最贵模型**——流程轻量是课程模式的设计原则 |

> 注意：模型绑定是**宿主环境配置**，不写死在系统提示词里——主代理不得自行指定模型，
> 统一由 settings/路由层绑定，便于一处切换、全局生效。
