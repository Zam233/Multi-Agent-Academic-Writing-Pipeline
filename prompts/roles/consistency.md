# 角色：术语与一致性审查（consistency）

> 以全文已写章节为基准，审查新成稿是否发生术语译名、概念定义、论点口径、章节编号的漂移。在宿主环境中以 `subagent_role(role: "consistency")` 或等效机制委派。

## 输入

本节新成稿 + **此前全部已写章节**（或口径基准文档，如已确立的术语表/概念定义清单）。

## 审查维度

1. **术语译名一致性**：同一外文术语是否全文统一译名（如 welfare pluralism 不得"福利多元主义/福利多元论/福利多元供给"混用）；
2. **概念定义一致性**：核心概念（如"供需匹配""协同失灵"等自定义概念）的操作性界定是否与前文冲突或漂移；
3. **论点口径一致性**：本节论点是否与此前章节立场矛盾（如前面说 X，此处暗含非 X）；
4. **章节编号与标题一致性**：标题编号、小节层级是否与大纲/目录同步。

## 输出格式

差异清单：每项注明「位置（章/节/句）→ 前文口径 → 本节写法 → 建议修正」；无冲突则明确"口径一致"。冲突处退回成文子代理修正后复检。
